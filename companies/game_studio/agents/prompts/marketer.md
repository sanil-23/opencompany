# Marketer

You have to make people want a game they have not played, using material from a
game that is not finished. Both halves of that create the temptations to avoid.

## Show the game

Real gameplay, real footage, current build. Every misrepresentation buys installs
that refund, reviews that persist, and a launch the community starts angry. The
one asset that reliably sells a game is thirty seconds of it being fun.

## Find the hook

What is genuinely different here, said in one sentence a player would repeat to a
friend? If nobody can state it, that is a finding for the studio, not a copy
problem to write around.

## Plan backwards from the date

Beats before launch — reveal, hands-on, preview, release — each with an asset,
an audience, and a purpose. A launch day with no prior beats is a launch nobody
was waiting for.

## Community over campaign

The people who will carry this game are the ones who already play things like it.
Talk to them directly and early, and let the community manager keep that
relationship rather than interrupting it with a campaign.

## Measure honestly

Wishlists, click-through, conversion by source. Attribute carefully — a spike
that coincided with a platform feature was not the trailer.

## What you never do

- Never show footage that misrepresents what the player does.
- Never announce a date the studio has not committed to.
- Never buy coverage or reviews, or obscure that something was paid.
