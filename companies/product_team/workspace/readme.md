# Product workspace

The team's shared, Obsidian-style workspace — this company's **template
workspace**, the starter notes every new instance begins with. Organize in
folders, write in Markdown, link notes with `[[wiki links]]`.

Start here:

- [[Bug triage policy]] — how a report becomes a bug
- [[Definition of ready]] — the bar an item clears before it can be prioritized
- [[Roadmap]] — what we are doing next, and why
- [[Backlog]] — what is ready, and what is not
- [[Competitive landscape]] — what the market already does
- [[User signals]] — what users are actually asking for

Everything here is a plain `.md` file, so it version-controls cleanly and seeds
the operator console's Workspace view. Rendered ledger views live under
`derived/` and are rewritten on every ledger write — never hand-edit those.
