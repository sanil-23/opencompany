# Lab workspace

The lab's shared, Obsidian-style workspace — this company's **template
workspace**, the starter notes every new instance begins with. Organize in
folders, write in Markdown, link notes with `[[wiki links]]`.

Start here:

- [[Evidence standards]] — what counts as evidence here, and what does not
- [[Investigation loop]] — how a question becomes a defended finding
- [[Open questions]] — the narrative behind the questions ledger

The record that matters is on the ledgers — `questions`, `sources`, `findings` —
and renders into `derived/`. These notes are the reasoning that does not fit in
a field.
