# Evidence grading

What this organization is allowed to treat as support for a target or a
compound.

| Kind | What it supports |
| --- | --- |
| Human genetic evidence | The strongest routine signal that modulating this target changes this disease |
| Clinical evidence in a related mechanism | Strong, if the mechanism really is the same one |
| Pharmacological evidence in an animal model | Real, and routinely over-read across species |
| In vitro activity | The compound does something in a dish |
| In silico prediction | A hypothesis with a number attached. **Not a result.** |

Reporting a simulation as a result is the specific way computational discovery
misleads people, and it is easy to do by accident when the number is precise.

Check that every citation is still current — retracted and superseded papers
are cited confidently for years. See [[Research standards]] and the
[[Safety discipline]].
