# Measurement standards

How this agency is allowed to report a number.

| Rule | The failure it prevents |
| --- | --- |
| The measure is fixed on the `campaigns` row before launch | A campaign judged on whatever it turned out to be good at |
| Figures come from the source dashboard, with the date range and currency stated | A report nobody can trace, which is a report that will be wrong in public |
| Both arms of a test are recorded on `experiments` | Accumulating confidence and no knowledge |
| `inconclusive` is reported as `inconclusive` | Noise reported as insight |
| What cannot be attributed is named as unattributed | A report that explains everything has invented something |

A running test's numbers are not a result. Read them and every test wins.
