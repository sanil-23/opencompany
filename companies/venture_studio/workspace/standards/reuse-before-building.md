# Reuse before building

A studio that builds six ventures and shares nothing is six startups with a
shared office. The sharing does not happen by proximity; it happens because
somebody wrote down that the thing exists.

- **Check `shared-assets` before building anything.** This is the studio's
  entire economic argument, and it only holds if somebody actually looks.
- **Register what you build** that another venture could use — services,
  playbooks, contracts, integrations, supplier relationships.
- **State the cost to adopt honestly.** Overstate how easy it is and the next
  venture rebuilds it anyway, having wasted a week first.
- **Every shared asset has an owner.** An unowned one becomes an unmaintained
  dependency for everybody, which is worse than not sharing.
- **An asset with one user is not shared yet.** It is a component that happens
  to be listed.
