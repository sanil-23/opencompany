# Lab workspace

The lab's shared, Obsidian-style workspace — this company's **template
workspace**, the starter notes every new instance begins with. Organize in
folders, write in Markdown, link notes with `[[wiki links]]`.

Start here:

- [[How we solve]] — the house method, and why each rule is a rule
- [[Solve loop]] — how a stated problem becomes a recorded answer
- `Solutions/` — one note per settled problem, written by the scribe

The record that matters is on the ledgers — `attempts` and `answers` — and
renders into `derived/`. These notes are the reasoning that does not fit in a
field.
